Sinkronizirano

Napomena o adresi pokretanja:

Trenutno je aplikacija otvorena lokalno (). Za Google prijavu i PWA instalaciju na Samsung S24, postavite ovu datoteku na besplatni HTTPS hosting (npr. Netlify Drop ili GitHub Pages).

Kako besplatno dobiti Client ID u 2 minute? Upute ▼
  1. Otvorite console.cloud.google.com i prijavite se svojim Gmail računom.
  2. Kliknite New Project (npr. naziv Moja Jamstva) i otvorite ga.
  3. U izborniku lijevo idite na APIs & Services → Library, pronađite Google Drive API i kliknite Enable.
  4. Idite na OAuth consent screen → odaberite External → upišite naziv aplikacije i svoj Gmail, a pod Test users dodajte svoj Gmail.
  5. Idite na Credentials → Create Credentials → OAuth client ID → odaberite Web application.
  6. Pod Authorized JavaScript origins dodajte adresu na kojoj otvarate aplikaciju (npr. https://vasa-stranica.netlify.app).
  7. Kopirajte dobiveni Client ID u polje iznad i kliknite Poveži Google Drive!

Instalacija i Sigurnosna kopija

Kako instalirati kao pravu aplikaciju na Samsung S24?

Android i Samsung Internet / Chrome zahtijevaju sigurnu HTTPS adresu kako bi prikazali gumb "Instaliraj aplikaciju" (bez adresne trake preglednika) i omogućili Google Drive prijavu:

  1. Preuzmite ovu HTML datoteku (gumb ispod) i preimenujte je u index.html.
  2. Besplatno je povucite na app.netlify.com/drop ili GitHub Pages — odmah dobivate svoj privatni https://... link.
  3. Otvorite taj link u Chromeu na svom Samsung S24 i kliknite Instaliraj aplikaciju (ili u izborniku Dodaj na početni zaslon → Instaliraj).
